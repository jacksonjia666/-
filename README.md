# Queensland Snake

A tiny, offline Android snake game inspired by five well-known venomous snakes found in Queensland.

## Snakes

- Eastern brown snake
- Coastal taipan
- Common death adder
- Red-bellied black snake
- Tiger snake

The simple pixel-like colours are stylised game art, not an identification guide. Never approach or handle a wild snake.

## Build

Requires JDK 17 and Android SDK 35.

```bash
gradle assembleDebug
```

GitHub Actions also builds a downloadable debug APK after every push to `main`.

## Controls

Choose a snake and tap **PLAY**. Swipe anywhere to steer. Tap the score area at the top-left to return to snake selection.
